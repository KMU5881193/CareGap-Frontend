# 이미지 에셋

생성한 PNG 원본을 편집하지 않고 assets/images에 포함했습니다. 생성 이미지 사용 범위는 돌봄틈새 AI 앱의 디자인 에셋입니다. 실제 인물·복지기관·상담 연결 화면을 나타내지 않습니다.

| 파일 | 적용 |
|---|---|
| brand_mark_v1.png | 로고·네이티브 아이콘·시작 화면 |
| care_hero_v1.png | 대상자와 담당자, 온보딩·상담 기록·건강 복지 |
| welfare_home_v1.png | 일정 카드·주거 복지 |
| elder_avatar_v1.png | 대상자 역할·프로필·기록 아바타 |
| staff_avatar_v1.png | 담당자 역할·기록·관리자 아바타 |
| family_care_v1.png | 가족 역할·가족 연결·생활 돌봄 |
| meal_support_v1.png | 식생활 지원 카드 |
| ai_guide_v1.png | AI 결과 안내 배너 |

추가 이미지 제작 방향: 제공된 앱 목업을 스타일 참고로 사용해 따뜻한 민트·세이지·크림·라벤더의 부드러운 편집 일러스트로 제작했습니다. 로고는 녹색 두 사람과 하트/노란 손, 대상자는 은회색 곱슬머리와 라벤더 상의, 담당자는 갈색 머리와 아이보리 상의·푸른 목걸이 명찰, 가족은 어르신과 딸·아들, 식사는 균형 잡힌 한식 트레이, AI는 종이를 든 민트색 흰 로봇으로 각각 생성했습니다. 화면용 문자를 이미지에 넣지 않고 Flutter 텍스트로 별도 구현했습니다.

Pretendard 폰트 원본·OFL 고지는 assets/fonts에 보관했습니다. Material Icons는 Flutter에서 제공하는 라이선스 고지를 따릅니다.
